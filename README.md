# blouinpest.com — Keystone 7A build

Astro static, zero client JS, Vercel target. Node 20+.

```bash
npm install
npm run build           # gen-authorised → astro check → astro build → npm run verify
npm run audit:rendered  # axe-core + overflow, real browser, 16 templates x 2 viewports
npm run dev
```

`audit:rendered` is separate from `verify` on purpose: it needs a Chromium
binary, so it would fail a CI box that has none. `verify` is the gate; the
rendered audit is the thing you run before a design change ships.

## Layout

- `src/data/business.ts` — every NAP, credential and proof string. One edit, whole site.
- `src/data/services.ts` — the service tree and the problem pages under each spoke.
- `src/data/authorised.ts` — GENERATED. Part 6A demand gate. Source of truth for which geography may be indexed or linked.
- `architecture/demand/demand-map.csv` — the evidence behind that gate. Edit this, then regenerate.
- `src/lib/schema.ts` — the single hand-built `@graph`, emitted once in BaseLayout.
- `scripts/` — the verification harness. `npm run verify` runs all ten checks, including `gate-integrity.mjs`, which asserts the Part 6A gate against the rendered output.
- `src/styles/base.css` — the whole design system, one file. Contrast ratios are recorded beside the tokens.
- `scripts/axe-audit.mjs` — rendered accessibility audit; serves `dist/` itself, so it needs no running server.
- `DESIGN.md` — what the visual system is, what it was modelled on, and the measured ratios.
- `PERFORMANCE.md` — Dimension 9 lab measurement and how to reproduce it.
- `MIGRATION.md` — the cutover runbook.

## Deploy

Vercel framework preset must be **Astro** explicitly. `vercel.json` carries 117
legacy redirects generated by `scripts/gen-redirects.mjs`; regenerate it whenever
the demand map changes.

Read `GUARDRAILS.md` before changing anything that looks broken.
