# Cutover runbook — blouinpest.com

Squarespace → Astro static on Vercel. Written 23 September 2026.
Nothing in here happens without the client's explicit go-ahead, and nothing on
the live site is touched until step 3.

## Before cutover day

**1. Access, confirmed in writing.**
- Domain registrar login (who owns blouinpest.com, and where the nameservers point today).
- Squarespace account — confirm the subscription is in Ryan's name, not a third party's.
- Google Business Profile: manager access for us, ownership stays with Ryan.
- Google Search Console: if a property exists, add us. If not, create one for the domain and verify by DNS, which survives the platform change.
- Where email for the domain is hosted. This is the item that breaks cutovers.

**2. Baseline, captured before anything changes.**
- Export the current Search Console performance data (16 months if available), and the index coverage report.
- Record current rankings for the handful of terms that matter: pest control + Lewiston, Auburn, Portland, and the service terms.
- Save a crawl of the live site so the legacy URL set is a matter of record. The 117 URLs are already in `architecture/demand/legacy-urls.txt`.
- Screenshot the Google Business Profile as it stands.

**3. Attestations in, per GUARDRAILS.md.** Licence number and categories, hours, bio, guarantee decision, and the four old claims resolved. The site can go live without them; it just goes live quieter than it needs to be.

## Cutover day

**4. Deploy to Vercel on a preview URL.** Framework preset must be set to **Astro** explicitly, or every route 404s on a build that reports success. Check: home, one service page, one problem page, /sitemap.xml, /robots.txt, and a gated town page (it must return noindex and must not appear in any sitemap).

**5. Point the domain.** Add blouinpest.com and www.blouinpest.com to the Vercel project, set one as canonical (www, matching `astro.config.mjs`), and update DNS at the registrar. Keep TTLs low for 24 hours beforehand if you can.

**6. Turn off the Squarespace built-in domain.** `smilodon-gopher-2m26.squarespace.com` currently serves the entire site at HTTP 200 and Google has indexed it. Disable it in Squarespace, or redirect it. This is the single highest-value technical fix in the whole engagement and it takes about a minute.

**7. Keep the Squarespace subscription running for 30 days.** Do not cancel on cutover day. If DNS needs rolling back, you want the old site still alive.

## Immediately after

**8. Verify the redirects.** `vercel.json` carries 117 of them, generated by `scripts/gen-redirects.mjs`. Spot-check: an old town URL, an old county URL, `/rodent-control-maine`, `/about`, `/reviews`. Every one should be a single 301 to a live page — no chains, no loops.

**9. Search Console.**
- Submit `/sitemap.xml` (the index) plus the four tier sitemaps.
- Use the URL inspection tool on the homepage and one service page, and request indexing.
- Watch coverage for the legacy URLs moving to "Page with redirect" over the following weeks. That is the expected outcome, not an error.

**10. Google Business Profile.** Update the website link if it changes shape, confirm the primary category, add the service list, set service areas (20 maximum — use the counties rather than every town), publish hours, and add photographs. The profile is the asset most likely to move the needle in the first month.

**11. Tell the answer engines nothing.** There is no submission process. What matters is that the HTML is reachable, the entity graph is complete and the content is citable — all three are already true.

## The first 30 days

- Week 1: watch for 404s in Vercel logs and in Search Console. Fix any legacy URL nobody predicted.
- Week 2: Lighthouse five-run mobile median for the Dimension 9 gate, recorded in the file.
- Week 4: INP field check at 28 days. First citability re-score. First look at branded-search volume as the Dimension 13 baseline.
- Ongoing: as job history arrives, flip towns from PENDING to PAGE in `architecture/demand/demand-map.csv`, regenerate, and write the page to the four M1 substance items. Re-run `scripts/gen-redirects.mjs` so the legacy URLs for that town point at the real page instead of the service-area hub.

## Rollback

If anything goes materially wrong, point DNS back at Squarespace. That is why the subscription stays live for 30 days. Nothing in this build modifies the existing site, so the rollback is a DNS change and nothing else.
